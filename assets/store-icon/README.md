# Exact Search Guard Store Icon

This folder contains the Shopify App Store icon for Exact Search Guard.

## Upload asset

- `exact-search-guard-icon-1200.png`
- 1200 x 1200 px
- PNG, sRGB
- No text, no screenshots, no Shopify marks, no WorksBien branding

## Design principle

The icon uses one simple mark: a magnifying glass over product-code bars with a confirmed-match badge. It is intended to communicate exact SKU/barcode lookup and search guardrails at small Shopify listing sizes.

## Source

- `exact-search-guard-icon.svg` is the editable vector source.
- `generate_exact_search_guard_icon.py` regenerates the PNG exports using Pillow.
