# Shopify Listing Copy

This is the locked English listing copy for Exact Search Guard.

## App Name

Exact Search Guard

**Rationale:** Short, under Shopify's 30-character limit, consistent with `shopify.app.toml`, and specific enough to distinguish the app from broad AI search and filter suites.

## App Card Subtitle

Send SKU, barcode and part-number searches to the right product

**Rationale:** Leads with the merchant-facing benefit, includes the highest-intent search terms naturally, and avoids keyword stuffing, statistics, pricing, or unsupported guarantees.

## App Introduction

Help SKU, barcode and part-number shoppers reach the right product without replacing store search.

## App Details

Exact Search Guard adds a focused exact-code layer to your existing storefront search. It indexes product identifiers such as SKUs, barcodes, handles, aliases and optional model-number metafields, then routes identifier-shaped searches to matching products or variants. If a query is not a verified exact match, the app leaves Shopify search in place. The admin dashboard helps merchants review duplicate identifiers, missing SKUs, unresolved searches and recovered exact-code lookups.

## Feature List

- Route exact SKU, barcode and part-number searches to matching products
- Keep native Shopify search as the fallback for ordinary queries
- Review duplicate, ambiguous and missing product identifiers
- Test identifier searches before enabling storefront behavior
- Track unresolved code-like searches for catalog cleanup
- Use a theme app embed with no manual theme file edits
